# 功能规格：入口服作为 LobbyCluster 成员与多入口选择

> 状态：已落地（并入 A1/A2/A4，无独立开发轨道；ADR-0083 已接受）　·　关联 PRD：FR-225（增强 FR-200 / **ADR-0075** / **ADR-0083**）　·　分支：feature/entry-server-as-lobby-member

## 1. 背景与目标

> ⚠️ 已按评审重写。原稿要新建「入口服**列表** + **轮询/ranked**」并让 BC 首次落脚优先取它——这与已落地的 **ADR-0075** 直接冲突。

**ADR-0075（已接受）** 确立：

- 每个 namespace **有且仅有一个** DB 权威 `LobbyCluster`；成员**必须显式指派**，不得由启发式推断。
- BC 首次落脚**只**走「LobbyCluster 候选 + **共享纯排序契约**」（过滤不可调度 → 最高健康分 → 容量占用率低者 → 可注入随机源）。
- 明文约束：**「不新增大厅专属权重、阈值、轮询或全局预留」**。
- `server.is_default_entry` / `zoneDefaultEntry` 仍存在，但只表达 **Zone 内业务默认入口**，**不参与**新 BC 首次落脚。
- ADR-0031 相关部分已被精确取代。

因此「入口服列表 + 轮询」正是 ADR-0075 **点名禁止**的第二套落脚真源；原稿会把刚落地的模型顶掉。

**修正后的目标**：把 `login-1` / `login-2` 这类入口（登录）服**作为 LobbyCluster 成员**纳入既有单一调度器；多入口分流由既有共享排序契约天然实现，**不新建第二真源**。**`is_entry` 展示标记本期不做**（ADR-0083 决策 3）。配套新开 **ADR-0083**。

## 2. 需求（要什么）

- 入口 / 登录服 = **LobbyCluster 的成员**（显式指派，走 ADR-0075 的归属迁移与排空门）。
- **多入口分流**：直接复用 ADR-0075 的共享候选 + 排序契约（健康分 / 容量 / 随机），**不新增轮询 / 权重 / 阈值**。
- **展示标记：本期不做**——ADR-0083 决策 3 已定 `is_entry` 本期不引入（入口服 = 大厅成员，语义重合）；将来确有展示需求时另行评估。
- **零第二真源**：不新增入口服列表端点作为落脚依据；不触碰 `isDefaultEntry` 既有语义。

范围内：把入口服指派为大厅成员、复用既有选择契约。
不做（范围外）：入口服列表作为独立落脚真源；大厅专属轮询 / 权重 / 预留；改 `isDefaultEntry` / `zoneDefaultEntry` 语义；数据面执行玩家连接（ADR-0017）。

## 3. 设计（怎么做）

- **归属**：`login-1/2` 经既有「未分配 backend → LobbyCluster」迁移指派（ADR-0075 决策 2 的排空门 + 原子审计），**不新增表**。
- **选择**：BC 首次落脚完全沿用 ADR-0075 决策 4——控制面生成 namespace 唯一 LobbyCluster 候选快照，按共享排序契约取一个；**入口服只是候选中的成员**，不特殊化。
- **展示标记：本期不做**（ADR-0083 决策 3）。若将来确有需求，另立 `server.is_entry`（或等价）**纯展示标记**，但须保证它**不进入**排序 / 过滤逻辑（否则即构成第二真源）。
- **不变量**（沿用 ADR-0075）：大厅成员 `lobby_cluster_id != NULL` 时 `zone_id` / `bc_cluster_id` 等互斥字段为 NULL 且 `is_default_entry=false`。
- **决策固化**：见 [ADR-0083](../adr/0083-entry-server-as-lobby-member.md)。

## 4. UX / 交互

- 用户任务：把登录服纳入大厅，并看清哪些大厅成员是入口。
- 进入路径：大厅集群视图（既有 LobbyCluster 管理）指派成员。
- 操作闭环：把 `login-1/2` 指派进大厅集群 → 大厅集群 `ready=true` → 拓扑显示入口标记 → BC 首次落脚按既有调度选其一。
- 状态设计：大厅为空 → 未就绪（既有）。
- IA 挂载：集群域；**不新增页面**（复用既有大厅集群管理入口）。

## 6. 验收标准

- `login-1/2` 可作为大厅成员被指派；指派后大厅集群 `ready=true`。
- BC 首次落脚**只**经既有共享排序契约选一个候选；**无**第二套入口列表参与决策（代码审查 + 端到端验证）。
- （如做）拓扑 / 资产可辨识入口服；标记**不影响**候选过滤与排序结果（可用注入固定随机源断言）。
- `isDefaultEntry` / `zoneDefaultEntry` 语义**未变**。
