# 功能规格：服务器资产页交互冻结与真实操作闭环

> 状态：已实现待真实集群联调　·　关联 PRD：FR-137（复用 FR-10 / FR-49 / FR-80 / FR-88 / FR-91 / FR-110）　·　分支：codex/file-sync-wizard

## 1. 背景与目标

`/servers` 服务器资产页已经改成高密度运维面板，但当前细节仍未冻结：点击反馈弱、详情入口不完整、部分操作缺少统一确认与结果反馈，导致它不像一个可交付的千级服务器运维页面。

本规格把 `/servers` 作为当前冻结页处理：在不新增高风险远程命令的前提下，补齐行点击动画、详情模态框、只读诊断、配置时间线、文件浏览、排空 / 下线 / 重同步 / 改派等已有后端能力的真实闭环。目标是在 1920x1080、浏览器 100% 缩放场景下，页面主体可一屏掌握，详情和深层操作通过模态框承载。

## 2. 需求（要什么）

- 行点击只做选择：点击任意服务器行时，表格高亮、右侧详情面板切换，并带轻量过渡动画；点击行本身不弹模态框。
- 详情模态框由显式入口打开：行内「详情」或右侧面板「打开详情」打开全量详情模态框，模态框包含「概览、健康、配置变更、Agent 日志、文件浏览、命令记录」六个区块。
- 操作必须真实接后端：
  - 下线 / 取消下线：调用 `POST /instances/{serverId}/offline` 与 `DELETE /instances/{serverId}/offline`，必须二次确认、展示提交中 / 成功 / 失败。
  - 排空 / 取消排空：调用 `PUT /scheduling/drains` 与 `DELETE /scheduling/drains`，必须二次确认、展示提交中 / 成功 / 失败。
  - 改派小区：复用现有改派对话框与 `PUT /zones/assignments` 能力，成功后刷新列表和详情。
  - 强制重同步：调用 `POST /instances/{serverId}/resync`，展示命令 ID，并在详情里能看到该服务器最近命令记录。
  - Agent 日志：调用 `POST /instances/{serverId}/logs` 触发，再调用 `GET /instances/{serverId}/logs` 查看结果，不展示未脱敏原文之外的任何额外敏感信息。
  - 文件浏览：调用 `GET /instances/{serverId}/browse`，只读浏览 `plugins/`，支持目录列表与文本文件预览；二进制、越权、超时等失败必须给出明确状态。
  - 配置变更：调用 `GET /instances/{serverId}/config-timeline`，展示时间线、版本、作用域、操作者与备注。
  - 命令记录：调用 `GET /commands?serverId=...`，展示最近命令状态，不展示瞬态敏感载荷。
- 操作入口状态要可理解：离线、未选中、权限不足、进行中请求分别显示禁用或错误文案，不能静默失败。
- 页面保持千级列表可用：筛选区、指标区、表格、右侧详情在 1920x1080 下不互相挤压；主页面不锁死滚动，表格滚动承载千级数据。
- 范围内：`/servers` 页面、服务器详情组件、相关 API 客户端调用、现有后端端点的最小缺口修复与测试补强。
- 不做（范围外）：重启服务器、执行任意命令、批量下线 / 批量排空 / 批量重同步、绕过现有 agent 命令通道的新能力、后端新增数据库表或新远程传输通道。

## 3. 设计（怎么做）

### 3.1 前端

- `ServersPage` 保持现有三栏结构：筛选与指标在顶部，服务器表格在中间主区域，右侧为当前选中服务器的紧凑详情。
- 行点击状态由单一 `selectedServerId` 驱动，行样式使用已有表格风格叠加选中背景、左侧蓝色标识、过渡阴影；键盘焦点与鼠标悬停样式一致。
- 新增或收敛一个服务器详情模态框组件，使用受控 `open` 状态，不替代右侧详情面板：
  - 概览：基础字段、状态、版本、容量、最近心跳。
  - 健康：TPS、CPU、内存、磁盘、健康原因与最近变化。
  - 配置变更：消费 `serverConfigTimeline`。
  - Agent 日志：消费 `requestAgentLogs` / `getAgentLogs`，按命令状态展示。
  - 文件浏览：消费 `browse`，路径导航只允许相对路径。
  - 命令记录：消费 `listCommands({ serverId, namespace, size })`。
- 所有写操作走统一确认模态框：标题、影响对象、原因输入（需要时）、确认按钮 loading、错误展示、成功后刷新相关 query。
- 不引入新前端依赖；复用现有 UI 组件、表格样式、toast、dialog / sheet / command 相关组件。

### 3.2 后端

- 以现有控制面接口为准，不复制业务逻辑：
  - `InstanceHandler` 提供实例详情、下线、取消下线、配置时间线、日志、重同步、浏览。
  - `SchedulingHandler` 提供排空与取消排空。
  - `CommandObserveHandler` 提供命令记录。
  - `ZoneAssignment` 相关端点提供改派。
- 若发现前端需要但客户端未封装的既有端点，只补 API client 与测试；若发现端点行为与文档不一致，只做最小修复并补后端集成测试。
- 不新增数据库表、不新增 agent 命令类型、不改变公开 API 的请求 / 响应结构。

### 3.3 安全与性能

- 下线、排空、重同步、取日志、文件浏览均沿用既有鉴权与审计；readonly 密钥不能触发有副作用操作。
- 文件浏览只读，遵守 `plugins/` 根路径限制；前端不得拼接绝对路径、盘符、`..`。
- 千级列表不做前端逐行远程请求；详情数据只在选中或打开模态框后按需请求。
- 批量危险操作暂不以客户端循环调用单机 API 的方式实现，避免在 1000+ 服务器场景制造不可控写风暴。

## 5. 验收标准

- 1920x1080、浏览器 100% 缩放下，`/servers` 首页筛选、指标、主表格、右侧详情均可见；主页面不锁定滚动，表格滚动可承载 1000+ 行。
- 点击表格行只切换右侧详情并有明确选中动画；只有点击「详情」入口才打开详情模态框。
- 详情模态框可查看概览、健康、配置变更、Agent 日志、文件浏览、命令记录；每个区块都有加载、空态、失败态。
- 下线 / 取消下线、排空 / 取消排空、改派、强制重同步均调用真实接口，成功后刷新页面状态，失败时保留错误信息。
- 前端 `pnpm test`、`pnpm lint`、`pnpm build` 通过。
- 后端相关 `go test` 通过；若改动后端业务逻辑，则 `go test ./...` 通过。
- Playwright 真实浏览器断言通过，并保存 `/servers` 页面和详情模态框截图。
- 不新增高风险远程命令，不新增数据库表，不引入新第三方依赖。

## 6. 风险 / 待定

- 本次冻结复用已有后端能力，重点是把页面交互与真实接口串成闭环；如果审核要求新增批量危险操作，需要另立规格设计服务端批量 API 与并发保护。
- 文件浏览、日志、重同步依赖在线 agent；离线实例只能展示失败原因和禁用动作，不做前端假成功。
- 真实 MC 集群端到端验收不在本机可完全模拟，本机验收以控制面集成测试、前端真实浏览器和 mock API 行为为准。
