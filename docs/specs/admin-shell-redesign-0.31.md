# 功能规格：管理台壳层重做（0.31 对齐中间版）

> 状态：开发中（FR-186～189 实现已合入 dev）　·　关联 PRD：FR-186～FR-189　·　版本线：0.31.x  
> 探讨记录：`.tmp/brainstorm-shell-header-sidebar-2026-07-21.md`（不入库）

## 1. 背景与目标

v0.30.0 收口交付编排后、进入 1.0.0 前，管理台壳层存在明显可用性问题：

- 身份重复：侧栏底部「运 / admin / 超级管理员」与页眉 `OperatorMenu` 同时展示。
- 侧栏折叠：`md:hidden` 整栏消失，无图标轨、无宽度动画，折叠后无法只靠图标导航。
- 页眉能力单薄：无全局运维指标条；工具位未对齐现代运维台（ReClaude 式双段）。

目标：在现有明亮 SaaS 视觉上精修壳层（不推倒主题、不改业务页内容），对齐参考站双段页眉 + 图标轨侧栏，并接上控制面全局态真数据与轻量移动适配。

## 2. 需求（要什么）

### FR-186 侧栏图标轨折叠与动画

- 桌面（`md+`）：展开约 232px ↔ 折叠约 60px **图标轨**；`width` / 主区 `padding-left` 有过渡动画。
- 折叠态：品牌仅 logo；导航仅图标，文案经 `title` / `aria-label` / tooltip 可达；分组标题隐藏或缩为分隔线。
- **删除侧栏底部操作人块**（身份只在页眉，见 FR-187）。
- 折叠触发钮贴侧栏右缘，随宽动画位移。
- 范围内：`apps/web` shell（sidebar / app-shell / store）与 shell 测试。
- 不做：业务页、导航 IA 重排、主题系统。

### FR-187 双段页眉与身份收敛

- **段 1**：全局运维指标条槽位（数据由 FR-188 填充）。
- **段 2**：左 `EnvFilter`（FR-178 行为不回退）；右：搜索 / 语言 / 通知 **占位** + 用户头像下拉（名、角色、登出）。
- 真鉴权：身份与登出 **仅页眉一处**；去掉「用户名文本 + 独立登出按钮」平铺。
- 演示模式：仍显 demo 徽标 + `ScenarioSwitcher`（与真鉴权互斥，沿用现逻辑）。
- 范围内：`header` / `operator-menu` / 相关 i18n 与测试。
- 不做：命令面板真搜索、i18n 切换真逻辑、通知中心真列表、RBAC。

### FR-188 全局运维指标条真数据

- 段 1 跨页固定五项：
  1. 控制面在线（`fetchSystemStatus` 或等价）
  2. Agent 在线数（`fetchServers` 聚合 online）
  3. 待确认注册（identities pending 计数）
  4. 未处理告警（alert-events 未关闭计数）
  5. 进行中变更单（活跃状态变更单计数）
- **优先**复用现有 list/status API 在前端聚合；仅当性能/权限明显不够时再补轻量 summary 端点并同步 API 文档。
- 单项失败降级为「—」，不整条崩溃；低频轮询 15–30s，切页不丢、不请求风暴。
- 演示模式 mock 提供稳定假数。
- 不做：页内业务 KPI 迁移、大屏 wallboard。

### FR-189 小屏抽屉侧栏

- `<md`：侧栏默认不占位；汉堡打开抽屉 + 遮罩；点遮罩或导航后关闭。
- 桌面图标轨逻辑不套用到小屏。
- 与 FR-186 折叠态互不污染（resize 行为可预期）。
- 不做：完整响应式重排业务页表格/表单。

## 3. 设计（怎么做）

仅前端壳层为主（`apps/web/src/shell/*`、`store.ts`、必要 `api/*` 聚合 hook）；无架构 ADR 变更（布局决策落在本 spec）。

| 模块 | 改动要点 |
|---|---|
| `store.ts` | `sidebarCollapsed` 保留；可增 `mobileNavOpen`（FR-189） |
| `sidebar.tsx` | 宽度 class + transition；折叠图标轨；去底部身份；分组标题折叠态处理 |
| `app-shell.tsx` | 主区 `pl` 同步 transition；折叠钮位置；小屏汉堡 + 抽屉（FR-189） |
| `header.tsx` | 拆为段 1 `MetricsStrip` + 段 2 工具条 |
| `operator-menu.tsx` | 头像下拉菜单（登出逻辑不变） |
| 新 hook（如 `useGlobalOpsMetrics`） | 并行 query + 聚合五项（FR-188） |
| 测试 | 扩展 `shell.test.tsx`、auth/logout 不回归；指标 hook 单测 |

## 4. UX / 交互

- 用户任务：运维在任意页快速看全局态、切环境、折叠侧栏腾宽度、窄屏也能导航与登出。
- 进入路径：登录后任意管理台路由即见壳层。
- 操作闭环：折叠/展开 → 图标导航 → 看指标 → 切 env → 用户菜单登出。
- 状态：指标加载中可用骨架或静默上次值；错误单项「—」；小屏抽屉打开时锁背景滚动可选。
- IA：不改 `docs/UX.md` 页面挂载；仅壳层结构。历史 Legacy 规格 `two-layer-header-and-env-context.md`（FR-105）不作为本版 apps/web 实现真源，本文件为 0.31 真源。

## 6. 验收标准

对齐 PRD FR-186～189 行内验收；汇总：

1. 桌面折叠后图标轨可导航，有宽度动画，侧栏无重复身份。
2. 页眉两段；身份仅页眉；env 与登出行为不回退。
3. 段 1 五项真数据或单项降级；轮询不风暴；mock/真机可抽查。
4. 窄视口抽屉可用，与桌面态不互相破坏。
5. `apps/web` 相关测试绿；真机 Browser 折叠/登出/指标抽查。
